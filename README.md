# Portfolio - Fernando Joel Bonilla Guerrero

Personal portfolio for presenting my work as a Software Engineer. The site
highlights selected projects in full-stack development, artificial intelligence,
data, and mobile applications, with bilingual content in Spanish and English.

## Overview

This portfolio is designed for quick professional review: recruiters and teams
can see my technical focus, featured projects, role in each project, results,
technologies used, repository links, live demos, and contact information.

## Featured Areas

- Full-stack web applications with React, Node.js, FastAPI, and modern UI tools.
- AI and computer vision projects using Python, PyTorch, TensorFlow, OpenCV,
  YOLO, U-Net, CNNs, fuzzy logic, and genetic algorithms.
- Data-oriented projects with ETL, dashboards, reporting, and structured
  analysis workflows.
- Responsive, accessible interfaces with dark/light theme support and smooth
  interactions.
- Bilingual experience: Spanish and English.

## Tech Stack

| Area | Tools |
| --- | --- |
| Frontend | React 19, Vite, Tailwind CSS |
| UI/Animation | Framer Motion, lucide-react |
| Code Quality | ESLint |
| Deployment | Vercel |

## Run Locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
